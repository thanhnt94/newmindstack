Hướng dẫn kết nối

Để Mindstack có thể sử dụng Auth Center làm hệ thống đăng nhập tập trung:

  • Đảm bảo Auth Center API URL là địa chỉ mà server Mindstack có thể gọi tới (Internal network).
  • Auth Center Web URL là địa chỉ mà người dùng truy cập từ trình duyệt.
  • Đăng ký Mindstack trong danh sách Clients của Auth Center để lấy Client ID và Client Secret.
  • Sau khi thay đổi, hệ thống sẽ tự động ưu tiên dữ liệu từ Database thay vì file .env.

Lưu ý: Nếu cấu hình sai và không thể đăng nhập, hãy sử dụng đường dẫn /auth/emergency-login hoặc chỉnh sửa trực tiếp trong bảng app_settings của database.
